# What is Green Steps Chicago?

Green Steps Chicago is a web application that helps users track the environmental impact of their daily transportation activities. Users can log activities such as driving, biking, or using public transport. The system calculates the carbon emissions generated from these activities and stores the information for analysis.

The application provides a dashboard where users can view their activity history, total carbon emissions, and summary metrics over time.

The goal of the project is to help users become more aware of their carbon footprint and encourage environmentally friendly travel habits.

# Main Features

Users can register and log in to the system.

Users can record transportation activities.

The system automatically calculates carbon emissions.

Activities are stored in the database.

Users can view their activity history.

The dashboard displays summary statistics and charts.

The system connects the frontend and backend using REST APIs.

Data is managed using Spring Boot, JPA, and an H2 in-memory database.

# System Architecture

The application follows a full-stack architecture consisting of:

Frontend:

Built using React

Displays dashboards, forms, and charts

Sends requests to backend APIs

Backend:

Built using Spring Boot

Handles business logic, activity management, and carbon calculations

Exposes REST API endpoints

Database:

Uses H2 in-memory database

Stores users and activity records

# How It Works?

A user logs an activity through the frontend interface.

The frontend sends the activity data to the backend using a REST API request.

The backend stores the activity in the database.

The system calculates the carbon emissions for that activity.

The dashboard service aggregates activity data to generate summary metrics.

The backend returns the processed data to the frontend.

The frontend displays charts, statistics, and recent activities on the dashboard.

Carbon emissions are estimated using the simplified formula:

Carbon Emissions (kg CO₂) = Distance (km) × Emission Factor

These values are stored and later used for dashboard calculations.

# Dashboard Metrics

The system includes a dashboard aggregation service that processes activity records and generates statistics for the user.

The dashboard includes:
Summary Metrics:
- Total activities
- Total distance traveled
- Total carbon emissions
- Average distance per activity
- Average carbon emissions

Transport Metrics:
- Groups activities by transportation mode (car, bike, etc.)
- Calculates totals for each mode

Daily Metrics:
- Aggregates activities by date
- Used to generate emission trend charts

Recent Activities:
- Displays the most recent activities logged by the user

These metrics are generated by the backend service and returned to the frontend for visualization.

# Assumptions and Limitations

Carbon emissions are estimated using simplified emission factors.

The system provides approximate values rather than exact environmental measurements.

The database is currently an H2 in-memory database, so data is lost when the backend stops.

Regional differences in emission factors are not yet implemented.

Some activity fields such as start and end locations are not currently stored.
