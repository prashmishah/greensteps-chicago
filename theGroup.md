# Definition of Done (Sprint 0)
---
## Feature Scope

 - [ ] Feature matches the approved project design
 - [ ] Feature aligns with intent-based carbon footprint tracking
 - [ ] No unnecessary or out-of-scope functionality added

## Functional Requirements

 - [ ] User intent is captured correctly
 - [ ] Context-aware inputs work as expected
 - [ ] Transport recommendations are generated correctly
 - [ ] Carbon footprint calculation is accurate
 - [ ] User can confirm and log activity
 - [ ] Activity appears in history view
 - [ ] Delete functionality works correctly
 - [ ] Invalid or empty inputs are handled safely

## Backend (Spring Boot)

 - [ ] REST endpoints implemented and reachable
 - [ ] Intent parsing logic implemented
 - [ ] Recommendation service implemented
 - [ ] Carbon calculator service implemented
 - [ ] JPA entities and repositories created/updated
 - [ ] Database interactions work correctly
 - [ ] No hardcoded credentials or secrets
 - [ ] Application starts without errors

## Database (PostgreSQL)

 - [ ] Tables created/updated correctly
 - [ ] Relationships and constraints validated
 - [ ] Data persists after restart
 - [ ] Delete operations reflect correctly
 - [ ] No unintended data loss

## Frontend (React + Vite)

 - [ ] UI renders without errors
 - [ ] Conditional forms behave correctly
 - [ ] Recommendation cards show correct data
 - [ ] Axios API calls succeed
 - [ ] History view updates correctly
 - [ ] Delete action updates UI and backend
 - [ ] No console errors or warnings

## Testing

 - [ ] API endpoints tested (Postman / PowerShell)
 - [ ] Backend logic tested with sample inputs
 - [ ] Database data verified
 - [ ] Frontend manually tested
 - [ ] No critical bugs found

## Code Quality & Git Standards

 - [ ] Code is readable and well-structured
 - [ ] Naming conventions followed
 - [ ] No commented-out or unused code
 - [ ] Meaningful commit messages used
 - [ ] Changes reviewed by at least one teammate

## Documentation

 - [ ] README updated (if required)
 - [ ] API behavior documented (if changed)
 - [ ] Feature is demo-ready
